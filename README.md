# Планировщик задач 

Веб-сервер для управления задачами с поддержкой повторяющихся событий.

# Функционал

- Создание, редактирование, удаление задач
- Отметка выполнения задач
- Поддержка повторяющихся задач

# Требования

- Доступ к порту 7540 

# Запуск тестов

go test ./tests

# Инструкция по запуску

- Запустите сервер: go run main.go
- Откройте в браузере: http://localhost:7540 

# Структура проекта

pkg/ основной код сервера
api/ обработчики api
db/ база данных
tests/ тесты
web/ фронтенд
main.go вход
